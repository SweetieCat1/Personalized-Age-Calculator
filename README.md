# Personalized-Age-Calculator

## Description
This project is a simple Python program created for the
CMPINF 0010 Version Control Skills Lab.

The program asks the user to enter their name and birth
year. It then calculates the age they will turn in 2026
and displays a personalized message.

## How to Use
1. Open the Jupyter Notebook.
2. Run the code cell.
3. Enter your name.
4. Enter your birth year.
5. View your calculated age.
